# Imported Fractal icons

These SVGs are copied byte-for-byte from simtropolis/fractal revision
`0613fab3abf72848cedbd982363c603317e092a7`.
`assets/design_systems/fractal-icon-sources.json` records each original path and
SHA-256. `fractal-icons.json` maps Made semantic names to these assets.

Files prefixed `fractal-` come from Fractal's original semantic additions and
are covered by Apache-2.0 in `assets/design_systems/LICENSE-APACHE`.
The remaining SVGs come from Fractal's Lucide/Feather base set and are covered
by the ISC/MIT terms in the adjacent `LICENSE`.

`UPSTREAM_PROVENANCE.md` and `UPSTREAM_THIRD_PARTY_NOTICES.md` preserve the
original notices verbatim; their paths and test names describe the upstream
repository. Made flattens both source directories here, prefixing original
Fractal additions to avoid name collisions. Made's existing semantic icon
registry supplies these files without a second icon or GPUI runtime.
